# Swisstopo for Garmin watches

Pre-built Custom Maps (KMZ) packs of Switzerland for the **Epix 2 / Epix Pro /
Fenix 7 Pro / Fenix 8** family. Open-source Swisstopo data, packaged so it fits
inside the watch's firmware tile cap.

## What you get on the watch

Either:

- **Winter ski-touring**: LK25 Winter raster (Swisstopo) + 4-class slope shading
  + SAC ski tours coloured by difficulty (blue / red / black).
- **Summer hiking**: LK25 Summer raster + slope shading + Wanderwege coloured
  by category (yellow / red / blue for Wanderweg / Bergwanderweg / Alpinwanderweg).
